## 一、范围与依据

- **本稿覆盖**：①解锁框（`UnlockModal`）②加密空间视图（`VaultPanel`，含锁定占位与空态）③隐私锁设置页（含未启用时的启用引导）④单篇加密的编辑器两态（`LockedDocPanel`）⑤四处状态标识（顶栏胶囊 / 空间节点 / 列表 / 编辑器）。
- **不做**：表格、附件、版本历史、回收站（M4）；MCP 令牌配置界面（M6）；分享与导出（M5）。
- **依据**：`docs/modules/Menote-隐私锁设计-v1.md` §4（状态与时效）、§9（标识与文案）、§11（走查表）；原型锚点 `#unlockOverlay` / `#resetPwOverlay` / `#tierMenuHtml` / `#lockCapsule` / `#vaultNode` / `.vault-empty` 可直接对照。
- **移动端**：本稿按桌面稿写，但遵守 DESIGN.md §2.4 底线（弹性布局、不以悬停/右键为唯一入口、触屏命中区、不发明移动端布局）。

## 二、解锁框 `UnlockModal`

**触发**（四处）：顶栏胶囊（锁定态）、侧边栏空间节点、Memo / 待办占位里的「解锁」、单篇加密条目。

**单篇场景的触发方式（2026-10-04 订正）**：**选中即弹**——点开一条「已加密且本次未解密」的笔记，解锁框**直接弹出**，不再需要先点正文区占位面板上的「解锁此篇」（那多一步，是用户 2026-10-04 明确要求去掉的）。两条配套口径：

- **占位面板上的「解锁此篇」按钮保留**：用户按 `Esc` / 点遮罩关掉窗后，仍要有路回去（DESIGN.md §5.4-3「空状态必须给出口」）。它与自动弹窗并存，不是二选一。
- **同一篇不重复弹、关掉不立刻再弹**：`unlockedItems` 在解密成功后会变化，自动弹窗的判据因此会在解密成功的瞬间再次成立——不挡住就会立刻再糊一次窗。用户主动关掉更是明确的拒绝，立刻重弹等于不让人拒绝。

**块（自上而下）**：

| # | 块 | 内容 |
|---|---|---|
| 1 | 标题 | 隐私锁场景：「解锁隐私锁」；单篇场景：「解锁此篇」；副标题一句话说明范围（"解锁后范围内内容可见，单篇加密条目仍需各自解密"） |
| 2 | 密码 | 单个密码字段（`type=password`，`autocomplete="current-password"`），自动聚焦 |
| 3 | 错误行 | 密码错误："隐私密码错误，请重试"；连续失败后追加"请等待 N 秒"（**本地**计次、逐次加等待，不联网） |
| 4 | 档位（仅隐私锁场景） | 三档单选（`radioset`）：本次会话 / N 分钟（默认，显示当前 N）/ 本次设备长期；**这里选的是本次临时档位**，不改设置默认值 |
| 5 | 忘记密码 | 文字链接「忘记隐私密码」→ 打开重置流程（§四 卡片②的第二入口） |
| 6 | 底部 | 主按钮「解锁」；次按钮「取消」（`Esc` 与点遮罩同样关闭） |

**主操作**：解锁。**空状态**：无。

**边界**：

- **未启用隐私锁**：不开本框——点相关入口走**启用引导**（§五）。
- **离线且本地无校验材料**：密码字段与「解锁」置灰，错误行位置显示"需要联网校验隐私密码"，不提供任何"放宽"入口。
- **两种变体的校验路径不同**（**2026-10-04 订正**）：范围变体校验通过后**打开范围门禁**；单篇变体校验通过后**只把这一篇**记进"本次会话已解密"，**不动范围门禁**——两道门禁正交（设计 §2.2、`model.ts` 头注）。用户只想看一篇，不该顺带解锁整个加密空间与范围内的 Memo。
- **设备长期档**：首次选择时必须勾选风险确认（"这等于在该设备上关闭隐私保护，任何能打开这个浏览器的人都能看到私密内容"），未勾选时「解锁」禁用。
- **单篇场景**不显示档位块（单篇的时效固定为本次浏览器会话，见设计 §4.5）。

## 三、加密空间视图 `VaultPanel`

空间节点在主操作区打开后的两种形态：

### 3.1 锁定态

- 主操作区**只有一个占位**：「此空间已锁定」+ 一行说明 + 主按钮「解锁」；**不显示条目列表、不显示空态**。
- 侧边栏节点：实心灰锁 + **条目数照常显示** + 无展开箭头；点击 = 打开解锁框。
- 若锁定发生在打开空间内条目的瞬间：正文区切 `LockedDocPanel`（标题明文 + 解锁按钮）。

### 3.2 解锁态

- 与笔记本**同构**的「列表 + 正文」双栏（复用 `TwoPane` / `ItemListHead` / `NoteWorkspace` 的既有结构），**不另起骨架**。
- 侧边栏节点：开锁图标，作为普通文件夹树展开；空间内文件夹名带小锁角标。
- 空间节点的「更多」菜单：**重命名空间**、新建文件夹、新建笔记、新建表格（沿用笔记本节点的 `+` 与菜单形态）。
- 空间内文件夹：与普通文件夹**同一套两层规则与校验**（非法目标置灰并说明原因）。
- 空间内新建的条目**天然带标记**，界面上**不出现加密勾选**（去掉了勾选，也不显示"加密"胶囊）。

### 3.3 空态 `VaultDocEmpty`

- 未选中条目时：居中占位——"选择一个条目，或在这里新建" + 主操作按钮；下方一行 `InfoHint`（ⓘ）说明保护边界（"内容在你的服务器上是明文存储的，受前端门禁与备份加密保护"）。

### 3.4 批量标记进度

- 空间节点或文件夹名后显示"处理中 12 / 40"；失败结束后在空间顶部出现一条失败清单条（可展开 + 「重试」）。

## 四、隐私锁设置页（设置 › 隐私锁）

M3 起该分类**进入设置导航**（M2 只做只读占位、不进导航）。卡片顺序即操作顺序：

| # | 卡片 | 内容与主操作 |
|---|---|---|
| ① | **状态** | 未启用：一句用途说明 + 主按钮「启用隐私锁」（走启用流程：两次输入密码 → 如实告知保护边界）；已启用：状态文字（已锁定 / 已解锁 · 档位）+ 按钮「立即锁定」（锁全部） |
| ② | **隐私密码** | 「修改隐私密码」（需先解锁；成功后说明"已导出的旧备份仍用旧密码"）、「忘记隐私密码 → 重置」（直接设新密码，两次输入；**重置不丢内容**，唯一后果是旧备份解不开——重置前必须明确提示并建议先解开旧备份） |
| ③ | **解锁档位** | 三档单选（`radioset`，默认「N 分钟」）+ N 分钟取值（1 / 5 / 15 / 30 / 60，默认 5）；说明"档位只决定门禁保持多久" |
| ④ | **隐私范围** | 加密空间一行（**只读**，带说明"始终在范围内"）+ Memo 一行（`toggle`，默认开，说明"带 Memo 衍生的待办一起"）+ 预留扩展位（一行灰字"后续内容类型可加入范围"，M3 不提供开关） |
| ⑤ | **搜索** | 「解锁时可搜索加密内容」（`toggle`，默认开）+ 说明"只影响正文；标题按各自的可见性参与搜索" |
| ⑥ | **关闭隐私锁** | 危险区（`danger`）：有隐私内容时按钮禁用并写明原因（"请先取消全部单篇标记并清空加密空间"）；无隐私内容时解锁后可关闭，关闭后再确认一次 |

**边界**：

- 未启用时只显示 ①（其余卡片不出现，避免空入口）。
- 离线时：启用 / 修改 / 重置 / 关闭 四个入口置灰并说明"需要联网"；档位、范围、搜索设置**可离线改**（本地设置 + 后续同步）。
- 文案红线（设计 §9.3）：不出现"加密存储""数据已加密"等表述；说明性文字一律进 `InfoHint`，警告与破坏性后果保持可见。

## 五、启用引导（未启用隐私锁时的入口行为）

| 入口 | 未启用时的行为 |
|---|---|
| 侧边栏空间节点 | 照常显示（锁图标 + "未启用"），点击后**不打开解锁框**：主操作区显示"加密空间是什么 + 能做什么"的说明页与主按钮「启用隐私锁」，点它跳到设置 › 隐私锁 |
| 编辑器「更多」菜单的「加密此篇」 | 点击后同上引导（菜单项不禁用） |

| 顶栏胶囊 | **不显示**（定稿 M02-05） |

## 六、单篇加密的两态与四处标识

按《隐私锁设计》§9.2 实现，四条要点：

1. **两套标识不可混用**：隐私锁态走顶栏胶囊 + 空间节点；单篇态走列表行锁标识 + 编辑器标题旁锁胶囊。同屏时两者**同时可见**。
2. **列表行**：未解密 → 明文标题 + 锁图标 + 摘要位"已加密"（不显示字数）；已解密 → 开锁图标 + 正常摘要。空间内条目（解锁期间出现在三视图）→ 标题前小锁角标 + "加密空间"标注。
3. **编辑器**：打开未解密单篇时正文区为 `LockedDocPanel`（标题明文可读 + 解锁按钮）；已解密时标题旁锁胶囊 + 底部状态栏一条（"加密笔记 · 已解密 · 4:32 后自动锁定" + 右侧「立即锁定」）。
4. **搜索结果**：解锁期间命中的空间内条目带"解锁期间可见"；未解密单篇的**标题**命中带"已加密"标注。

## 七、与 DESIGN.md、components.md 的对照

| 项 | 取值 |
|---|---|
| 控件选型 | 解锁框与重置流程用 `Modal` / `Overlay`（点遮罩关闭、打开时焦点移入、`role="dialog"`）；档位与范围开关用既有 `radioset` / `toggle`；危险操作（关闭隐私锁、清空空间）用 `danger` 按钮；不引入新控件类型 |
