## 一、现状与目标的差距

原型的结构（`menote-framework.html` 第 03 屏）：

```text
概括预览（甲板）
  ├─ 左：今日待办（焦点卡，flex:1.15）
  └─ 右（flex:1）
       ├─ 上：条目统计三数字带（flex:none）
       └─ 下：最近动态（grow）
快捷方式：页内一条横排动作带（高 54px，带组名）
快速导航：文件夹 / 标签 / 常用视图 三组
```

逐块对照**当前实现**：

| 块 | 现状 | 与原型 |
|---|---|---|
| 概括预览 | `home__grid` **三块等分**（`StatCards` / `TodayTasks` / `RecentActivity`） | ❌ 要改成**甲板：一主两副** |
| 快捷方式 | `ShortcutGrid` 是一张**独立卡片**（`.home-card`） | ❌ 要改成**页内一条动作带** |
| 快速导航 | `QuickNav` 已按**文件夹 / 标签 / 常用视图**三组铺 | ✅ 已一致 |
| 动作带的五个动作 | 齐了（新建笔记 / 记录 Memo / 新建待办 / 打开加密空间 / 搜索） | ✅ 动作齐了，但**「打开加密空间」是过期的禁用** |

**外加两处过期事实**（M3 落地隐私锁之后没人回来改）：

| 位置 | 现状文案 | 问题 |
|---|---|---|
| `ShortcutGrid.tsx:41-43` | `disabled` + `title="加密空间将在 M3 启用"` | M3 早就做完了，这颗按钮**永远点不动** |

## 二、块一：概括预览改甲板

```
┌ 概括预览 ──────────────────────────────────────────────┐
│ ┌ 今日待办 ────────────┐ ┌ 条目统计 ───────────────┐ │
│ │ 来自清单 Memo         │ │ 笔记 12 │ 表格 3 │ Memo 48│ │
│ │                      │ └────────────────────────┘ │
│ │ ● 交电费      今天    │ ┌ 最近动态 ───────────────┐ │
│ │ ● 回邮件      明天    │ │ 改动过的笔记与表格      │ │
│ │                      │ │                        │ │
│ │ [打开待办视图 →]      │ │                        │ │
│ └──────────────────────┘ └────────────────────────┘ │
└───────────────────────────────────────────────────────┘
```

| 点 | 怎么落 |
|---|---|
| **布局** | 一行两列：左焦点卡 `flex: 1.15`、右栏 `flex: 1`；右栏内上段三数字带 `flex: none`、下段最近动态 `grow`。**全部用弹性**，不写固定宽 |
| **今日待办** | 复用现有 `TodayTasks` 的**内容**（列表 / 锁定占位 / 空态三态都不动），只换成焦点卡外壳 |
| **「打开待办视图」出口** | 焦点卡头部右侧一个弱操作。**这是原型明写的一条**（"带一个『打开待办视图』出口"），现在没有 |
| **条目统计** | 复用 `StatCards` 的**数字与口径**（统计**始终按全量**、不因锁定改变——`DESIGN.md` 与《隐私锁设计》§9.2 的既有口径），只把三块卡壳收成**一条三数字带** |
| **最近动态** | 复用 `RecentActivity`，含它那行恒在的 Memo 提示（"另有 N 条"或"已锁定"） |
| **锁定态** | 三块的占位规则**一字不改**：统计照数、只有 Memo 派生的内容预览占位 |

**为什么焦点卡给待办**：待办是唯一有**时间压力**的内容，统计与动态是"回顾性"的。原型把"现在要做的事"放最大、"看过什么"放右栏，是按这个来的。

## 三、块二：快捷方式改动作带

```
┌ 快捷方式 ──────────────────────────────────────────────┐
│ [+ 新建笔记] [🕐 记录 Memo] [☑ 新建待办] [🔒 打开加密空间] [🔍 搜索] │
└───────────────────────────────────────────────────────┘
```

| 点 | 怎么落 |
|---|---|
| **形态** | 从一张独立卡片（`.home-card`，占一整块高度）收成**一行横排**，高度约 54px。组名「快捷方式」作为一行标题保留在带上方（原型 `cap()` 的写法） |
| **不铺满** | 原型原话「**三块都只给出口、不铺满内容**」——这五个就是出口，不加"最近用过的模板"之类的东西 |
| **图标** | 全走既有 `Icon`（`plus` / `clock` / `check-square` / `lock` / `search`），**不新增图标**、不用 emoji（`DESIGN.md` §5.5） |
| **触屏** | 按钮是原生 `button`、有文字标签、命中区不小于一行高——不依赖悬停（窄屏适配虽未定稿，但这条不构成"仅桌面成立"的写法） |

## 四、两处过期禁用：接上「打开加密空间」

**口径与功能栏那个贴底节点完全一致**（不发明第二套进入方式）：

| 加密空间状态 | 点「打开加密空间」 |
|---|---|
| **没启用**隐私锁 | 置灰 + **说明原因**（`DESIGN.md` §6.1：禁用必须说明为何）——「先在设置 › 隐私锁 启用」 |
| **已启用但锁定** | 打开**解锁弹窗**（同一套，不自己写一个） |
| **已启用且已解锁** | 切到加密空间视图（选中空间根那张文件夹卡） |

**这要加一条新回调**：`App → HomeView → HomePanel → ShortcutGrid / QuickNav`，命名为 `onOpenVault`。`HomePanel` 现在没有这个 prop，所以这是一次贯穿四层的透传——**只在 `app/` 与 `features/home/` 内部**，不碰 `features/notes` 的视图类型（复用既有的 `{ kind: "notebook", folderId }`）。

## 六、明确不做

| 不做 | 理由 |
|---|---|
| 「那年今日」 | 早已实现（§零） |
| 动首页那四个取数函数的口径 | 这轮是"怎么摆"，不是"算什么"。统计按全量、锁定只占位 Memo 派生内容，是《隐私锁设计》§9.2 的既有口径 |
| 首页按角色差异化 | 需求没写，首页对所有人一个样 |
| 移动端布局 | `DESIGN.md` §2.4 未定稿。**但不得留下仅桌面成立的写法**：甲板用弹性两列（不做固定宽 + 绝对定位）、动作带允许换行、按钮都是原生 `button` 且有文字 |
| 首页设置项 | 启动视图已有（设置 › 通用），首页不自己再造一个 |
